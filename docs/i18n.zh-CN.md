# 界面本地化

[English](i18n.en.md) · 简体中文

Audience: public

支持 English（`en`）和简体中文（`zh`）。`zh-TW` 暂复用简体节点文案以避免半中半英；欢迎贡献完整繁体翻译。

## 两层翻译

1. 标准节点使用 ComfyUI [官方自定义节点 i18n 布局](https://docs.comfy.org/custom-nodes/i18n)：`locales/<locale>/nodeDefs.json` 翻译标题、描述、输入输出名称、tooltip 和下拉显示标签。
2. Preview、Input Adapter、Runtime Monitor 自绘 DOM 使用 `web/i18n*.js`，监听相同 `Comfy.Locale`。官方节点目录尚不覆盖任意自定义前端组件文案。

某些 Nodes 2.0 版本翻译字段但不翻译下拉。我们的仅显示 `getOptionLabel` 适配器读取同一 /i18n 目录，**原地修改该方法，保留共享 options 对象、选项数组、当前值与回调**。参考 [i18n demo](https://github.com/comfyui-wiki/ComfyUI-i18n-demo) 与 [Easy-Use 目录](https://github.com/yolain/ComfyUI-Easy-Use/tree/main/locales)。

自绘目录用中文源消息与明确英文翻译；模板值按字面写入 textContent，不执行任意诊断内容，也不插入 HTML。

## 稳定工作流契约

翻译不能改变节点 ID、后端分类、插槽 ID/类型、下拉实际值、数值/布尔、路径、哈希、JSON、旧标签到 ID 的迁移、缓存键或执行参数。

nodeDefs 的 option 键是实际值，值仅为显示标签。没有独立迁移时，不将原中文/双语实际值替换为英文。测试要求选项集合完全匹配。

已知结构化媒体提示会翻译；未知 Worker、Proton、FFmpeg、系统错误保持原文。复制任务详情保留路径、哈希、参数及后端标识，便于排错。

## 添加文案

- 标准字段同步更新 en/zh nodeDefs；在独立繁体翻译维护前镜像到 zh-TW。
- 自绘字符串用 `t(...)` 或 t 标签模板，并补充 web/i18n_messages.js 英文条目。需实时切语言的静态标签使用 bindText，动态报告重新渲染。
- 不翻译用户素材名、本地路径或未知 payload。
- 源文与译文的占位符（如 {0}）必须相同。

```bash
node --test tests/*.mjs
python3 -m unittest discover -s tests -v
```

测试覆盖回退、字面插值、语言切换、目录完整性、实际值保护和示例接线。新增目录后重启 Comfy 并刷新浏览器；部分版本会动态发现目录，但不要据此假定所有版本无须重启。
